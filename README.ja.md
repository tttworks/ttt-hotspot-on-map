# TTT Hotspot on Map for Elementor

[English](README.md) | [中文](README.zh-CN.md) | **日本語**

**Elementor 向けのインタラクティブ・ホットスポットマップウィジェット** —— 任意の地図画像にマーカーを配置し、
各マーカーから個別の情報パネルを開けます。

## このウィジェットでできること

**カスタム Elementor ウィジェットをどこまで作り込めるか**を示すリファレンスです。
「画像に点を打つだけ」ではなく、小さなアプリケーションのように動作します。

### 編集体験

- **ドラッグで配置** —— エディタのキャンバス上でホットスポットを直接ドラッグして配置し、
  ワンクリックで座標を保存。数値の手入力は不要です。
- **項目数は無制限** —— ホットスポットのリストは利用者が自由に管理でき、
  パネル上で追加・削除・並べ替えができます。
- **必要なときだけ現れる設定** —— 高度なオプションは、対応する機能をオンにしたときだけ表示されます。
  編集画面が煩雑になりません。
- **レスポンシブごとの個別設定** —— デスクトップ / タブレット / モバイルで、
  調整できる項目ごとに別々の値を持てます。
- **使用するページだけを読み込み** —— スタイルとスクリプトは、そのウィジェットを含むページにのみ読み込まれます。
  サイト全体には影響しません。

### 見た目とインタラクション

- **ホットスポット間の曲線リンク** —— マーカー同士を名前で接続し、
  **曲がり具合と方向をパネルから調整**できます。固定の弧ではなく、実際に調整できる曲線です。
- **周回アニメーション** —— マーカーがマップ上を周回します。方向、実行方式（同時または順次）、
  速度モード、グロー、**軌跡のスタイル**まで設定できます。
- **拡大縮小してもズレない配置** —— マーカーは地図画像そのものに紐づき、
  コンテナのサイズ変更やブレークポイントの切り替え時に再投影されます。レイアウトが崩れません。
- **パルス表示** —— 注意を引くリング。拡大率はパネルから制御できます。
- **ホバー状態を標準搭載** —— マーカーとアイコンの両方に反応があります。

### エンジニアリング品質

- **依存関係なし** —— 素の JavaScript と CSS のみ。CDN も jQuery も不要です。
- **エディタに安全** —— 設定を変更するたびにクリーンに再描画され、
  マーカーの重複やイベントリスナーの残留が起きません。
- **設定がそのまま見た目に** —— 表示される色・サイズ・角丸はすべてウィジェット設定から反映されます。
  スタイルシートに固定値はありません。

## 改版履歴

**全 20 版 —— v1.0.0 から v1.0.20 まで。**

当プロジェクトで最も多く改版したウィジェットです。ほぼすべての版が**実際のコンテンツでの使用**から生まれました。
特定の幅でマーカーが重なる、情報パネルが画面外にはみ出す、単体では問題なく見えるアニメーションが
ページスクロールと干渉する —— ソース冒頭の改版履歴は、
「本番環境でしか見つからない問題のリスト」のようになっています。
