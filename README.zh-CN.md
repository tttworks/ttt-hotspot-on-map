# TTT Hotspot on Map for Elementor

[English](README.md) | **中文** | [日本語](README.ja.md)

**Elementor 互动地图热点组件** —— 在一张自定义地图图片上放置标记，每个标记可展开独立信息面板。

## 这个组件能做什么

它是「**自定义 Elementor 组件可以做到多深**」的一个参照 —— 更像一个小型应用，而不是"一张图加几个点"。

### 编辑体验

- **拖拽定位** —— 在编辑器画布上直接拖动热点摆位，一键保存坐标，无需手输数字
- **不限量扩展** —— 热点列表完全由使用者管理，在面板里自由增删、排序
- **按需显示的控件** —— 高级选项只在对应功能开启后才出现，编辑面板始终清爽
- **响应式独立配置** —— 桌面 / 平板 / 手机可以为每个可调项保留各自的数值
- **只在用到它的页面加载** —— 样式与脚本仅在实际包含该组件的页面加载，站点其余部分零负担

### 视觉与交互

- **热点之间的曲线连接** —— 把标记按名字互连，**弯曲程度与方向都能从面板调节**：是真正可调的曲线，而非固定弧线
- **环绕轨道动画** —— 标记可绕地图运动，方向、编排（同时或逐个）、速度模式、光晕与**运动拖尾样式**均可配置
- **缩放不散位** —— 标记锚定在底图本身，容器缩放、断点切换时自动重新投影，版式永不漂移
- **脉冲提示环** —— 吸引注意的光环，缩放比例由面板控制
- **内置悬停反馈** —— 标记与图标均有悬停状态

### 工程质量

- **零依赖** —— 纯原生 JavaScript 与 CSS，不引用任何 CDN，也不需要 jQuery
- **对编辑器安全** —— 每次改动设置都干净重绘，不会重复标记、不会残留事件监听
- **由设置驱动外观** —— 你看到的每一种颜色、尺寸、圆角都来自组件自身的设置，样式表里没有写死的视觉值
